## 3. 建议正文表述

> 在固定 KG、运行时和输入声明下，我们将实验扩展到 Caracas、Abidjan 和越南北部沿海走廊。C02/C04 在三个 AOI 上均重复运行完整方法与固定优先级变体；C06 因独立道路参考源仅在 Caracas 重复。完整方法在 7 个可比较案例中均保持计划有效、最终交付和证据完整，关键图层按时交付率为 6/7。固定优先级保持最终交付成功，但将关键图层按时交付率降至 3/7，并在 C02 中产生预期的道路优先顺序。

后半段必须保留限定语：本轮每个 AOI/变体只运行一次，统计量是探索性描述；外部匹配率只表示 OSM 与 HydroSheds 源的一致性代理；C06 缺少两个新增 AOI 的独立道路参考源，因此不能据此宣称跨地区道路质量门恢复能力。

## 4. 有效性威胁

- 外部有效性：三个 AOI 能扩大结构覆盖，但仍不足以覆盖不同国家、灾种、数据供应商和极端数据缺失模式。
- 构念有效性：HydroSheds 不是人工标注真值；代表点/线中点匹配不能评价完整几何、拓扑和属性质量。
- 统计结论：每个单元只有一次运行，比例型 95% CI 和 Cohen h 只用于描述，不用于显著性结论。
- 参考源覆盖：Abidjan 和越南北部沿海走廊缺少独立第二道路源，C06 的不可运行是数据覆盖缺口，不是系统失败观察。
- 环境外推：结果来自 memory KG、mock LLM、eager Celery、单 worker 和 local-only 环境，不能外推为真实 LLM、分布式调度或生产性能结论。
- 对照解释：固定优先级改变任务顺序，效果量反映任务调度敏感性，不单独证明融合质量提升。
