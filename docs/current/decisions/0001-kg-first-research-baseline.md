# 决策 0001：知识图谱优先的研究基线

> 状态：accepted  
> 日期：2026-07-28

## 背景

现有系统已经包含知识图谱、产品契约、规划、质量门和恢复机制，但部分灾害词汇、任务映射、质量阈值、数据源替代和决策权重仍散落在 Python 常量与函数中。若直接开展审计和消融，实验对象将是“知识图谱与隐藏硬编码的混合系统”，无法可靠归因 KG 的作用。

## 决策

1. 将契约化灾害知识图谱确立为研究主体。
2. 将 P0-R 与 P0-K1–K5 放在 P1 独立实验审计之前。
3. 后续运行默认读取版本化 KG 冻结包；必要决策知识缺失时 fail closed。
4. LLM 保持受约束计划提议者定位，其有效性与 KG 建模贡献分开验证。

## 影响

- 当前 A0 论文主线和优先级必须同步修订。
- KG v1 冻结前不扩大 AOI 或开展最终规划效果实验。
- 现有 Freeze C 继续作为工程证据基线，但不代表新的 KG v1 研究基线。
- 后续 KG 优化通过新版本进行，不覆盖已冻结版本。
