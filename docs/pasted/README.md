目录约定：

- `conversation-handoffs/`：历史 AI 会话交接。
- `legacy-research-notes/`：已被当前产品契约方向替代的研究笔记。
- `legacy-thesis/`：已被当前论文口径替代的论文或实验草稿。

不要从本目录恢复一个“当前计划”而不先核对 `docs/current/`、代码、测试和冻结证据。历史内容原则上保持原貌；需要纠正时，在当前文档中说明替代关系。
